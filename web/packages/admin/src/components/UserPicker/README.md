# UserPicker

授权用户选择器。左侧机构列表过滤，中间搜索并点整行勾选用户，右侧是已选，确认后 `emit('confirm', ids)`；用于角色授权等“按机构找人”的场景。

```vue
<UserPicker ref="userPickerRef" @confirm="onUserConfirm" />
```

- `excludeIds`：排除指定用户 Id，这些人在列表里整行置灰、标“已有”，不可选。
- `confirm`：携带选中用户 Id 数组（按选择顺序）。
- 打开时调用 `ref.open(ids?)`：不传按空态打开；传一个已选用户 Id 数组则先回显（角色授权页编辑时这样回填已有成员），也可用 `@confirm` 回调统一提交。

## 交互

- 点整行即选中 / 取消，行尾的圆形勾选标记只表示状态；“全选本页”会跳过 `excludeIds`，本页能选的都选上之后再点就是取消本页。
- 搜索框停顿 300 ms 后自动查询并回到第 1 页。后端用户分页只有“姓名”“账号”两个独立的模糊条件，没有联合检索，所以搜索框左侧的放大镜带下拉，在两者间切换，默认按姓名。
- 一页 20 人，底部是“共 N 人”和翻页。
- 已选超过 8 人时右栏才出现搜索框；移除钮悬停才显示（触屏档常显）。

## 屏幕形态

角色页「授权用户」的形态:

- 宽 / 中档:居中弹窗(固定弹窗,不跟随「表单形态」全局偏好),三栏 = 机构 | 可选用户 | 已选。
- 窄档(壳层 < 600):底部抽屉,三栏收成「可选用户 / 已选」两页(分段页签),机构换成可选用户页顶部的树选择。
- 内容区 < 900 但还不到窄档:仍是弹窗,但同样收成两页。
